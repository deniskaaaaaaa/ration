# Рацион из холодильника

Приложение для iPhone: вводишь цель (сушка, поддержание, набор) или свои КБЖУ, добавляешь продукты, которые есть дома, — и получаешь рацион на день с рецептами, граммовками и таблицами КБЖУ, подогнанными точно под цель. Всё считается на телефоне, без платного ИИ.

## Как добавлять продукты

- **Сканер** — живой сканер штрихкодов. КБЖУ берутся из встроенной базы Open Food Facts (миллионы продуктов), а если продукта там нет — из интернета.
- **Фото полки** — на снимке ищутся все штрихкоды сразу, фрукты и овощи узнаются по виду.
- **Этикетка** — фото таблицы Nutrition Facts или «Пищевая ценность», цифры переписываются сами.
- **Найти** — поиск по русскому каталогу обычных продуктов и по базе упаковок.
- **Всегда есть дома** — специи, соусы, масла: учитываются без фото, калории масла и соусов входят в КБЖУ.

## Как устроено

- `Core/` — движок без интерфейса (Swift, тестируется на Linux): расчёт цели по Миффлину — Сан Жеору, каталог продуктов на русском, шаблоны блюд, подбор рациона и подгонка граммов, разбор этикеток.
- `App/` — интерфейс на SwiftUI, камера (VisionKit, Vision), база продуктов (SQLite).
- `tools/build_db.py` — сборка базы `foods.sqlite` из выгрузки Open Food Facts; `tools/make_icon.py` — иконка.
- `.github/workflows/build.yml` — облачная сборка: тесты движка, база продуктов, `.ipa` в Releases (`latest`), отчёты в ветку `dist`.

## Установка

Скачай `Ratsion.ipa` со страницы Releases (`latest`) и поставь через Sideloadly с бесплатным Apple ID (приложение нужно переподписывать раз в 7 дней; данные сохраняются).

Данные о продуктах — Open Food Facts, лицензия Open Database License (ODbL).
